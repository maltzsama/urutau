# Changelog

## 0.1.0 (2026-09-15)

### Highlights

* **operator:** flat cpu/memory on the CR, single image for coordinator and workers
* **spec:** Workers becomes an object (number, cpu, memory)
* **enrich:** ColumnarJoin is kernels + one gather pass; no map, no joinKey
* **enrich:** fail the load on a join-key type mismatch
* **enrich:** snapshot is a typed Arrow table; joinKey is gone
* **dataplane:** delete BatchFromChangeBatch and bridge.go
* **enrich:** columnar broadcast join; delete the row path
* **transport:** __phase is a wire column; delete dead AddMetadata
